Schedule periods now run continuously from one scheduled delivery date to the day before the next, including mid-month and mid-quarter delivery dates. The scheduler's ratio `skip_empty` count now uses the same half-open interval overlap as the ratio preview. An interval ending precisely at the period start no longer makes an empty report appear non-empty. Migration `20261017000100_report_skip_empty_ratio_boundary.sql` was applied to the linked development project; a rollback-safe boundary test and the broader Group 13 SQL test pass.

CSV downloads now use one spreadsheet-safe cell encoder for Reports, audit history, and staff bulk export. It quotes delimiters and prefixes formula-like user text with a tab while leaving ordinary numeric values unchanged. Three local tests cover formula markers, embedded delimiters/quotes, and numeric cells. The prefix intentionally changes the raw text; any future ADP or other machine-import file needs its own validated schema rather than reusing this human-readable CSV format.
